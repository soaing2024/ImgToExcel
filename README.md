# ImgToExcel
这个项目完全为整活而存在……通过对excel单元格作为像素点进行自动涂色，将一张图片以excel表格的形式展示。至于实际用途……额……嗯……嗯。

## 🌟 项目介绍
这个项目通过将图片的每个像素点映射到Excel表格的单元格中，并设置对应的背景颜色，实现在Excel中"绘制"图片的效果。虽然可能没什么实际用途，但确实是个有趣的编程实验！

示例效果：
🖼️ → 📊 (将左边的图片转换为右边的Excel表格)

## 🛠️ 技术实现
### 核心原理
将图片分割为网格，每个网格单元对应一个Excel单元格

获取每个网格单元的平均/代表颜色

在Excel中设置对应单元格的背景颜色

### 关键技术点
使用Pillow(PIL)库处理图片

使用openpyxl库操作Excel文件

RGB颜色值转换为十六进制格式

Excel行列尺寸调整以适应像素点

### 脚本运行
准备:

将目标图片放在项目目录下

准备一个空白Excel文件(如1.xlsx)
cmd运行：pip install pillow openpyxl

运行脚本:

bash
python excel_image_painter.py
查看结果:

脚本会生成result.xlsx文件

## ⚠️ 注意事项
大图片会导致生成的Excel文件非常大！

Excel对单元格样式数量有限制

颜色可能会有轻微失真(因RGB→十六进制转换)

行高/列宽可能需要根据图片调整
